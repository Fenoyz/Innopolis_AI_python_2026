# Классы и объекты в Python: Руководство для начинающих разработчиков

Привет! Если ты уже уверенно умеешь писать циклы `for`/`while`, условия `if-elif-else` и создавать функции `def`, то пришло время перейти на уровень взрослой разработки — изучить **ООП (объектно-ориентированное программирование)**.

---

## 1. Зачем нужны классы?

Представь, что ты пишешь игру. Раньше для одного персонажа приходилось создавать кучу переменных:

```python
hero_name = "Артур"
hero_hp = 100
hero_attack = 15
```

А если в игре появляется 20 врагов? Заводить переменные `enemy1_name`, `enemy2_name`? Код превратится в неуправляемую кашу.

**Класс** решает эту проблему. Это чертёж (шаблон), по которому можно создавать сколько угодно одинаково устроенных, но независимых друг от друга персонажей, предметов или инструментов.

> **Аналогия из жизни:**  
> * **Класс** — это формочка для печенья или чертёж машины на заводе.  
> * **Объект (экземпляр / instance)** — это само печенье или конкретная машина, съехавшая с конвейера.

---

## 2. Основные термины

* **Класс (Class)** — шаблон, объединяющий характеристики и действия в одну сущность.
* **Объект (Экземпляр / Instance)** — конкретный экземпляр, созданный по этому шаблону.
* **Атрибут (Attribute)** — переменная внутри объекта (что у него *есть*: цвет, имя, здоровье).
* **Метод (Method)** — функция внутри класса (что он *умеет делать*: бегать, атаковать, перезаряжаться).

---

## 3. Магический метод `__init__` и загадочный `self`

Давай создадим наш первый класс робота:

```python
class Robot:
    # 1. Конструктор: вызывается автоматически при рождении робота
    def __init__(self, name: str, battery: int):
        self.name = name          # Атрибут: имя этого робота
        self.battery = battery    # Атрибут: заряд батареи

    # 2. Метод: действие, доступное роботу
    def say_hello(self):
        print(f"Бип-боп! Я {self.name}, заряд: {self.battery}%")

    def walk(self, distance: int):
        cost = distance * 2
        if self.battery >= cost:
            self.battery -= cost
            print(f"{self.name} прошёл {distance} м. Батарея: {self.battery}%")
        else:
            print(f"{self.name}: недостаточно энергии для прогулки!")
```

### Разбираемся в деталях:

1. **`__init__` (Конструктор)**  
   Двойные подчёркивания означают, что это специальный системный метод. Он запускается в момент создания объекта, чтобы задать ему начальные параметры.

2. **Что такое `self`?**  
   `self` в переводе с английского — «сам себя». Это ссылка на конкретный объект, с которым мы работаем прямо сейчас.  
   Когда роботов двое (например, Валли и Бендер), через `self.battery` программа понимает, чей именно аккумулятор сейчас разряжается, не путая их между собой.

---

## 4. Как создавать и использовать объекты

```python
# Создаём двух независимых роботов
robot_a = Robot("Валли", 20)
robot_b = Robot("Бендер", 100)

# Вызываем методы
robot_a.say_hello()   # Выведет: Бип-боп! Я Валли, заряд: 20%
robot_b.say_hello()   # Выведет: Бип-боп! Я Бендер, заряд: 100%

robot_a.walk(5)       # Валли тратит энергию (останется 10%)
robot_b.walk(5)       # Бендер тратит свою энергию (останется 90%)
```

Обрати внимание: изменения в `robot_a` никак не влияют на `robot_b`. Каждый живёт своей жизнью по единому набору правил!

## 5. Чек-лист для написания классов

- [ ] Имя класса пишется с большой буквы и в CamelCase (`SmartRobot`, `PlayerHero`).
- [ ] Первым параметром у любого метода обязательно указывается `self`.
- [ ] К любым внутренним переменным класса обращаемся строго через `self.переменная`.
