## Уровень 1: Разминка — «Герой RPG» 🛡️

### Задача
Создай класс `Hero` для текстовой RPG-игры.

### Требования:
1. Конструктор принимает `name` (имя) и необязательный параметр `hp` (здоровье, по умолчанию `100`).
2. Метод `take_damage(amount)`:
   - уменьшает здоровье героя на величину `amount`;
   - если здоровье падает ниже 0, оно должно остановиться ровно на `0` (никаких отрицательных жизней).
3. Метод `heal(amount)`:
   - восстанавливает здоровье на величину `amount`;
   - здоровье не может стать больше `100` (максимальный предел).
4. Метод `status()`:
   - выводит сообщение вида: `"[Имя] имеет [hp] HP"`.

## Уровень 2: Средний — «Копилка с PIN-кодом» 🔐

### Задача
Реализуй электронный сейф-копилку с защитой от подбора пароля.

### Требования:
1. Конструктор принимает начальный баланс `balance` (по умолчанию `0`) и строковый пин-код `pin` (например, `"1234"`). Также внутри инициализируется счётчик неверных попыток (`attempts = 0`) и флаг блокировки (`is_blocked = False`).
2. Метод `deposit(amount)`:
   - если копилка заблокирована — выводит сообщение об ошибке;
   - если сумма больше 0, прибавляет её к балансу.
3. Метод `withdraw(amount, entered_pin)`:
   - если копилка заблокирована — отказывает в операции;
   - если пин-код неверный: увеличивает счётчик ошибок. При достижении **3 неверных попыток** переводит копилку в режим блокировки (`is_blocked = True`);
   - если пин-код верный, но денег на балансе меньше, чем `amount` — сообщает о нехватке средств (попытки не сгорают);
   - если всё верно — списывает средства, сбрасывает счётчик ошибок и выводит выданную сумму.

## Уровень 3: Хардкор — «Арена дуэлей» ⚔️

### Задача
Напиши класс бойца и симулятор пошагового сражения между двумя персонажами с помощью цикла `while`.

### Требования:
1. Класс `Fighter`:
   - Атрибуты: `name`, `hp`, `attack_power`.
   - Метод `is_alive()`: возвращает `True`, если `hp > 0`, иначе `False`.
   - Метод `take_damage(damage)`: вычитает здоровье (минимум 0).
   - Метод `attack(target)`: принимает другого бойца (`target`) и наносит ему урон с небольшим рандомом. Урон рассчитывается как случайное число от `attack_power - 3` до `attack_power + 3` (используй функцию `randint` из модуля `random`).
2. **Основная логика боя (вне класса):**
   - Создай двух бойцов (например, «Рыцарь» и «Орк»).
   - В цикле `while` бойцы наносят удары по очереди каждый раунд.
   - Цикл прекращается, как только один из бойцов теряет всё здоровье.
   - В конце выводится имя победителя.

## Образец решения: Уровень 1 («Герой RPG»)

Попробуй сначала написать код самостоятельно. Если застрянешь — подсмотри сюда:

```python
class Hero:
    def __init__(self, name: str, hp: int = 100):
        self.name = name
        self.max_hp = 100
        self.hp = min(hp, self.max_hp)

    def take_damage(self, amount: int):
        damage = max(0, amount)  # Исключаем отрицательный урон
        self.hp = max(0, self.hp - damage)
        print(f"{self.name} получил {damage} урона. Осталось HP: {self.hp}")
        
        if self.hp == 0:
            print(f"💀 Герой {self.name} пал в бою!")

    def heal(self, amount: int):
        heal_val = max(0, amount)
        self.hp = min(self.max_hp, self.hp + heal_val)
        print(f"{self.name} восстановил {heal_val} HP. Текущее HP: {self.hp}")

    def status(self):
        print(f"Статус: {self.name} | HP: {self.hp}/{self.max_hp}")


# Проверяем работу героя:
hero = Hero("Артур")
hero.status()
hero.take_damage(45)
hero.heal(20)
hero.take_damage(100)  # HP не упадет ниже 0
hero.status()
```
