## Разминка с преподавателем ($10$ минут). «Рентген оперативной памяти»

Создай в папке `AI_Course` файл `memory_xray.py`, набери и запусти код ниже, чтобы увидеть реальные адреса объектов в оперативной памяти (RAM) и их размер в байтах:

```python
import sys  # системный модуль для проверки веса объектов в памяти

model_version = 4
temperature = 0.7
bot_name = "CyberBrain"
is_ready = True

print("int   | Адрес id:", id(model_version), "| Вес в RAM (байт):", sys.getsizeof(model_version))
print("float | Адрес id:", id(temperature),   "| Вес в RAM (байт):", sys.getsizeof(temperature))
print("str   | Адрес id:", id(bot_name),      "| Вес в RAM (байт):", sys.getsizeof(bot_name))
print("bool  | Адрес id:", id(is_ready),      "| Вес в RAM (байт):", sys.getsizeof(is_ready))

# Проверяем коварство input():
user_val = input("\nВведи любое число с клавиатуры: ")
print("Ты ввел:", user_val, "| Тип переменной:", type(user_val))
```

## 🔥 Задание 3 (Уровень «Босс»). Адаптивный ASCII-интерфейс и кэш интерпретатора `ascii_window_boss.py`

Создай в папке `AI_Course` исследовательский скрипт `ascii_window_boss.py` из двух частей:

* **Часть А — Самомасштабируемое окно терминала без `if`:**
  * Запроси у пользователя заголовок окна `title` и текст системного статуса `status`.
  * Вычисли максимальную длину из этих двух строк с помощью встроенной функции `max(len(title), len(status))`.

* **Часть Б — Детектор интернирования малых чисел (Small Integer Caching) в CPython:**
  * При старте Python заранее создает в оперативной памяти (RAM) массив целых чисел в диапазоне от $-5$ до $256$, чтобы не тратить память на их повторное создание.
