### Эталонное решение Уровня «Босс» (`feasibility_calc.py`)

```python
# Решение уровня «Босс» (Пара 4): feasibility_calc.py
def evaluate_hardware_fit(rows: int, features: int) -> None:
    """Оценивает расход RAM под табличный датасет для ПК с 16 ГБ ОЗУ (без CUDA)."""
    # 1 ячейка float64 = 8 байт; умножаем на 3 с учетом копий при обучении в scikit-learn
    estimated_bytes = max(0, rows) * max(0, features) * 8 * 3
    estimated_mb = estimated_bytes / (1024 ** 2)

    print(f"\n[РАСЧЕТ ПАМЯТИ] Размерность матрицы: {rows} x {features}")
    print(f"[РАСЧЕТ ПАМЯТИ] Пиковый расход ОЗУ с учетом копий: {estimated_mb:.2f} МБ из 16384 МБ")

    if estimated_mb < 500.0:
        print("ВЕРДИКТ ЖЕЛЕЗА: [ОТЛИЧНО] Легко обучится на процессоре Xeon за секунды!")
    elif estimated_mb < 4096.0:
        print("ВЕРДИКТ ЖЕЛЕЗА: [ДОПУСТИМО] Потребуется аккуратная фильтрация столбцов в Pandas.")
    else:
        print("ВЕРДИКТ ЖЕЛЕЗА: [РИСК ЗАВИСАНИЯ] Слишком тяжелый датасет для 16 ГБ RAM! Уменьши выборку.")


if __name__ == "__main__":
    print("=== ИНЖЕНЕРНЫЙ ПАСПОРТ И ОЦЕНКА РЕСУРСОВ ИИ-ПРОЕКТА ===")
    name = input("Название модуля / приложения: ")
    task_type = input("Тип ML-задачи (Регрессия / Классификация / Кластеризация): ")
    n_rows = int(input("Планируемое число строк (примеров) в датасете: "))
    n_cols = int(input("Планируемое число признаков (столбцов): "))

    print(f"\nПроект «{name}» ({task_type}) зарегистрирован.")
    evaluate_hardware_fit(n_rows, n_cols)
```

## 3. Ключи и критерии оценивания Контроля по Теме 1 (Урок 8 — $10$ баллов)

### Ответы на Блок А (по $1$ баллу за каждый пункт, максимум $6$ баллов):
1. **Тест Тьюринга:** Тест пройти может (так как тест проверяет только внешнюю имитацию переписки), но AGI он **не стал** — это узкий ИИ (Narrow AI) с программируемой задержкой и имитацией опечаток без сознания и понимания мира.
2. **«Зимы ИИ»:** 1) Нехватка вычислительной мощности процессоров того времени; 2) Отсутствие больших объемов оцифрованных данных (Big Data) и интернета (плюс завышенные ожидания инвесторов).
3. **Классика против ML:** В классическом программировании правила задает человек; в машинном обучении алгоритм сам выводит правила и зависимости из размеченных примеров.
4. **Резюме:** Историческое смещение выборки (historical / data bias) — модель выучила перекос старых данных по принципу GIGO, приняв название вуза за признак профессионализма.
5. **Галлюцинации:** Языковая модель не хранит проверенные факты как база данных, а статистически предсказывает наиболее вероятную последовательность токенов $P(w_t)$.
6. **Беспилотник:** Размытие юридической ответственности между пассажиром/владельцем машины, автоконцерном (датчики/тормоза) и компанией-разработчиком ПО автопилота.

### Ключи к Блоку Б — «Технический прокурор» (максимум $4$ балла: $1$ балл — дефект данных, $1$ балл — риск ложного срабатывания, $2$ балла — грамотное инженерное решение):
* **Вариант 1 (Зевание в школе):** *Дефект:* физиологическая реакция (нехватка кислорода в душном классе, недосып) ошибочно приравнена к плохому поведению. *Ложное срабатывание (false positive):* отличник зевнул в конце шестого урока и получил несправедливую двойку. *Решение:* использовать обезличенную статистику только для датчика проветривания кабинета, без персональных наказаний!
* **Вариант 2 (Бан за $65\%$ в голову):** *Дефект:* не учтена длина выборки и ранг игрока. *Ложное срабатывание:* новичок случайно попал $2$ выстрела из $3$ ($66.7\%$) в первом раунде или зашел киберспортсмен со снайперской винтовкой — честный игрок теряет аккаунт. *Решение:* учитывать минимум $50$ матчей, анализировать плавность движения мыши и отправлять спорные случаи на ручной патруль (human-in-the-loop).
* **Вариант 3 (Фото кожи в студии):** *Дефект:* сдвиг домена (domain shift) — нет снимков с бюджетных телефонов при домашнем желтом освещении. *Ложное срабатывание / пропуск:* в реальной жизни тень на фото даст ложный диагноз или пропустит опасный симптом (false negative). *Решение:* дополнить датасет любительскими снимками с разных камер и выдавать предупреждение «Требуется консультация врача», а не финальный диагноз.
