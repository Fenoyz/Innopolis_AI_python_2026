## 🎮 Как устроена практика: уровни «База» и «Босс»

В каждой папке темы вы найдете два главных файла к занятию:
* `theory_pair_XX.md` — краткий конспект урока со схемами, формулами и примерами кода.
* `tasks_pair_XX.md` — практические задачи с разделением на два уровня сложности:
  * 🛡 **Уровень «База»:** обязательный фундамент для уверенного освоения темы и сдачи контроля.
  * 🔥 **Уровень «Босс»:** задачи повышенной инженерной сложности (алгоритмическая оптимизация, работа с памятью, графический интерфейс на `tkinter`, архитектура модулей).
