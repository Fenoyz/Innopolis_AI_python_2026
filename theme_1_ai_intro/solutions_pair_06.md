## 1. Подводные камни, крайние случаи (edge cases) и железо

* **Риск зависания процессора Xeon на гигантских степенях (`**`):** Как только ребята узнают про возведение в степень, кто-нибудь обязательно попробует запустить `print(999999 ** 999999)`. В современном Python 3 целые числа имеют произвольную точность (arbitrary-precision integers), но перевод такого числа в десятичную строку для вывода на экран нагрузит ядро Intel Xeon E5-2620 v3 на $100\%$ и вызовет защитное исключение `ValueError: Exceeds the limit (4300 digits) for integer string conversion`. Предупреди об этом заранее как о крутом защитном механизме Python против зависаний серверов!
* **Крайний случай (edge case) деления `float` через `//`:** Обрати внимание ребят в Задании 1: если делить нацело дробные числа (`8000 // 12.5`), Python вернет `640.0` (тип `float`, а не `int`!). Чтобы получить чистое целое число штук без `.0`, результат `//` оборачиваем в `int()`.
* **Школьное округление отрицательных чисел (для «Босса»):** Формула $\text{int}(x + 0.5)$ идеально работает для всех $x \ge 0$, но для отрицательного числа $x = -2.5$ сумма даст $-2.0$, хотя по модулю округление от нуля должно давать $-3$. Отличный вопрос на подумать для твоего продвинутого разработчика!

## 2. Поминутный план и схемы для доски (Урок 11 — Теория, $40$ мин)

### Схема №1 на доске ($0\text{–}12$ мин): Три мины приведения типов
Запиши красным маркером:
1. `int("3.14")` $\longrightarrow$ ошибка `ValueError`! Верный мост: `int(float("3.14"))` $\longrightarrow$ `3`.
2. `int(3.99)` $\longrightarrow$ `3` (отсечение хвоста, а не округление!).
3. `bool("False")` $\longrightarrow$ `True` (строка не пустая!), `bool("")` $\longrightarrow$ `False`.

### Схема №2 на доске ($12\text{–}27$ мин): Деление уголком и операторы `//`, `%`
Нарисуй школьное деление столбиком $135$ секунд на $60$: частное $2$ (это `135 // 60`), остаток $15$ (это `135 % 60`). Запиши проверку:

$$135 = (135 \text{ // } 60) \times 60 + (135 \bmod 60) = 2 \times 60 + 15$$

### Схема №3 на доске ($27\text{–}40$ мин): Форматирование f-строк и двоичные дроби
Разбери шаблон `{переменная:формат}`:
* `{price:.2f}` — дробное число с $2$ знаками после точки.
* `{sec:02d}` — целое число минимум из $2$ цифр с нулем впереди (`07` вместо `7`).
Покажи фокус с `0.1 + 0.2` и объясни природу двоичных бесконечных дробей в процессоре.

# Решение уровня «База» (Пара 6, Задание 1): vram_planner.py
print("=== ПЛАНИРОВЩИК ВИДЕОПАМЯТИ RX 570 (8192 МБ) ===")

total_vram_mb = 8192
model_mb = int(input("Введите вес ИИ-модели в памяти (МБ): "))
image_mb = float(input("Введите вес одной картинки (МБ): ").replace(",", "."))

# Вычисляем свободную память, целое число картинок и остаток
free_vram_mb = total_vram_mb - model_mb
max_images = int(free_vram_mb // image_mb)
leftover_mb = free_vram_mb % image_mb

print("\n--- ОТЧЕТ РАСПРЕДЕЛЕНИЯ ПАМЯТИ ---")
print(f"Свободно под данные:  {free_vram_mb} МБ")
print(f"Влезет целых кадров:  {max_images} шт.")
print(f"Неиспользуемый запас: {leftover_mb:.1f} МБ")
```

# Решение уровня «База» (Пара 6, Задание 2): training_timer.py
print("=== СУТОЧНЫЙ ТАЙМЕР ОБУЧЕНИЯ НЕЙРОСЕТИ ===")

total_seconds = int(input("Введите общее время обучения в секундах (например, 100000): "))

# В сутках 86400 секунд, в часе 3600 секунд, в минуте 60 секунд
days = total_seconds // 86400
rem_after_days = total_seconds % 86400

hours = rem_after_days // 3600
rem_after_hours = rem_after_days % 3600

minutes = rem_after_hours // 60
seconds = rem_after_hours % 60

print(f"\nДней: {days} | Таймер: {hours:02d}:{minutes:02d}:{seconds:02d}")
```

# Решение уровня «Босс» (Пара 6, Задание 3): binary_dataset_boss.py
def test_school_rounding() -> None:
    """Сравнивает банковское округление Python и арифметическую формулу int(x + 0.5)."""
    print("=== ЧАСТЬ А: ТЕСТ МАТЕМАТИЧЕСКОГО ОКРУГЛЕНИЯ ===")
    for val in (2.4, 2.5, 3.5):
        school_val = int(val + 0.5)
        print(f"Число {val} -> round(): {round(val)} | Школьная формула int(x + 0.5): {school_val}")


def analyze_rgb_dataset() -> None:
    """Раскладывает битовый вес несжатого датасета изображений по ГБ, МБ, КБ и Байтам."""
    print("\n=== ЧАСТЬ Б: БИНАРНЫЙ АНАЛИЗАТОР ДАТАСЕТА ===")
    photos = int(input("Количество снимков в датасете: "))
    width = int(input("Ширина кадра (пикселей, например 1920): "))
    height = int(input("Высота кадра (пикселей, например 1080): "))
    bpp = int(input("Глубина цвета (бит на пиксель, например 24): "))

    total_bits = photos * width * height * bpp
    # Округляем вверх до целого байта на случай некратного числа бит: (bits + 7) // 8
    total_bytes = (total_bits + 7) // 8

    gb = total_bytes // (1024 ** 3)
    rem_gb = total_bytes % (1024 ** 3)

    mb = rem_gb // (1024 ** 2)
    rem_mb = rem_gb % (1024 ** 2)

    kb = rem_mb // 1024
    b = rem_mb % 1024

    print(f"\nСуммарный поток: {total_bits:,} бит ({total_bytes:,} байт)")
    print(f"Точный расклад:  {gb} ГБ | {mb} МБ | {kb} КБ | {b} Байт")


if __name__ == "__main__":
    test_school_rounding()
    analyze_rgb_dataset()
