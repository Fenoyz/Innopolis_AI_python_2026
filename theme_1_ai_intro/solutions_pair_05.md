## 1. Подводные камни, крайние случаи (edge cases) и железо

* **Почему нельзя объяснять переменную как «коробку»:** Если сейчас заложить метафору коробки, то на Теме 3 (списки / lists) ребята впадут в ступор на коде `a = [1, 2]; b = a; b.append(3)`. Модель «стикер-ссылка на объект в оперативной памяти (RAM)» с первого дня дает кристально точное понимание архитектуры Python!
* **Крайний случай (edge case) в задаче «Босса» с оптимизацией байт-кода (constant folding):** Если продвинутый ученик просто напишет в одном скрипте две строчки `a = 1000` и `b = 1000`, компилятор байт-кода современного CPython склеит одинаковые литералы внутри одного блока кода в один объект, и `id(a) == id(b)` вернет `True` даже для миллиона! Чтобы увидеть честную работу кэша малых чисел $[-5, 256]$ во время выполнения (runtime), числа нужно порождать вычислением на лету — например, `a = int(str(n))` и `b = int(str(n))`. Это отличный исследовательский инсайт для твоего разработчика!
* **Риск зависания графического буфера на $16\text{ ГБ}$ RAM:** Предупреди ребят, когда показываешь умножение строк в задаче с рамками, не умножать строку на миллиард (`"═" * 1_000_000_000`) — выделение гигабайтной строки и попытка вывести её в окно IDE надолго повесит интерфейс.

## 2. Поминутный план и схемы для доски (Урок 9 — Теория, $40$ мин)

### Схема №1 на доске ($0\text{–}15$ мин): Стикеры в RAM и Пакман (Garbage Collector)
* Рисуешь прямоугольник **RAM (16 GB)**, внутри облачко `100`, к нему стрелку от стикера `score`.
* Зачеркиваешь стрелку при команде `score = 200`, рисуешь новую стрелку к `200`, а возле бесхозной сотни рисуешь Пакмана — сборщик мусора (garbage collector).
* Выписываешь правила именования (snake_case): `max_hp` — верно; `1hp`, `max-hp` — ошибка `SyntaxError`.

### Схема №2 на доске ($15\text{–}25$ мин): Базовая четверка типов данных
* Пишешь в столбик: `int` ($42$), `float` ($3.14$ и $2.0$!), `str` (`"42"` в кавычках), `bool` (`True` / `False` строго с заглавной буквы).
* Вопрос на засыпку для класса: *«Какой тип у числа `0.0` и у текста `"False"`?»* (`float` и `str`).

### Схема №3 на доске ($25\text{–}40$ мин): Конвейер ввода и вывода

$$\text{Клавиатура} \longrightarrow \text{input()} \longrightarrow \text{ВСЕГДА str!} \longrightarrow \text{print(sep, end)} \longrightarrow \text{Монитор}$$

Разбираем работу параметров `sep`, `end` и управляющих символов `\n` (перенос) и `\t` (табуляция).

### Эталонное решение Задания 3 — Уровень «Босс» (`ascii_window_boss.py`)

```python
# Решение уровня «Босс» (Пара 5, Задание 3): ascii_window_boss.py
def draw_adaptive_box(title: str, status: str) -> None:
    """Рисует идеально выровненную двойную рамку под любую длину двух строк без if."""
    content_width = max(len(title), len(status))
    inner_width = content_width + 4  # по 2 пробела отступа слева и справа

    # Вычисляем количество пробелов добивки справа для каждой строки
    title_pad = content_width - len(title)
    status_pad = content_width - len(status)

    print("\n╔" + "═" * inner_width + "╗")
    print("║  " + title + " " * title_pad + "  ║")
    print("╠" + "═" * inner_width + "╣")
    print("║  " + status + " " * status_pad + "  ║")
    print("╚" + "═" * inner_width + "╝")


def detect_int_cache_bounds() -> None:
    """Экспериментально находит границы кэширования целых чисел (Small Integer Caching)."""
    cached_numbers = []

    for n in range(-20, 270):
        # Создаем два числа динамически через str(), обходя склейку констант компилятором
        a = int(str(n))
        b = int(str(n))
        if id(a) == id(b):
            cached_numbers.append(n)

    print("\n=== ИССЛЕДОВАНИЕ ОПЕРАТИВНОЙ ПАМЯТИ CPYTHON ===")
    if cached_numbers:
        print(f"Обнаружен диапазон интернирования int: от {min(cached_numbers)} до {max(cached_numbers)}")
        print(f"Всего предзагруженных объектов в RAM: {len(cached_numbers)} шт.")


if __name__ == "__main__":
    win_title = input("Введите заголовок терминального окна: ")
    win_status = input("Введите строку текущего статуса системы: ")

    draw_adaptive_box(win_title, win_status)
    detect_int_cache_bounds()
```
