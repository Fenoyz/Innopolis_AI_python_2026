## 🔥 Задание 3 (Уровень «Босс»). Математический движок рекомендаций `recommender_engine.py`

Реализуй настоящий прототип рекомендательной системы (Recommender System) игр на чистом Python без сторонних библиотек! Создай в папке `AI_Course` файл `recommender_engine.py`.

### Техническое задание:
* Создай базу данных из $5$ разных игр (словарь), где каждой игре сопоставлен вектор из $3$ числовых признаков от $0$ до $10$: `(Экшен, Тактика, Командность)`.
* Запроси у пользователя его собственный вектор предпочтений $U = (u_1, u_2, u_3)$ с клавиатуры.
* Для каждой игры с вектором $G = (g_1, g_2, g_3)$ вычисли **евклидово расстояние (Euclidean distance)** в трехмерном пространстве признаков:
  $$d(U, G) = \sqrt{(u_1 - g_1)^2 + (u_2 - g_2)^2 + (u_3 - g_3)^2}$$
* Переведи расстояние в процент совпадения (match score) и отсортируй список игр от самой подходящей (минимальное расстояние $d$) до наименее подходящей! Выведи топ рекомендаций с текстовыми шкалами совпадения.
