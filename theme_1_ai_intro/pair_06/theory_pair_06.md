## 1. Явное приведение типов (Type Casting) и его ловушки

Поскольку функция `input()` всегда возвращает строку (`str`), попытка сложить ввод пользователя с числом вызовет ошибку типа `TypeError`, а сложение двух строк просто склеит их друг с другом (**конкатенация строк / string concatenation**):

```python
print("10" + "20")            # Выведет строку: "1020"
print(int("10") + int("20"))  # Выведет число: 30
```

Для конвертации используются функции `int()`, `float()`, `str()` и `bool()`.

> [!CAUTION]
> **Три главные мины приведения типов в Python:**
> 1. **Дробная строка в `int()`:** вызов `int("3.14")` аварийно остановит программу с ошибкой `ValueError`! Сначала переводим строку в `float("3.14")`, и только потом при необходимости в `int()`.
> 2. **Отсечение вместо округления:** функция `int(3.99)` возвращает `3`, а не `4`! Она жестко отрубает дробную часть к нулю (**усечение / truncation**).
> 3. **Ловушка непустой строки в `bool()`:** вызовы `bool("False")` и `bool("0")` возвращают `True`! В Python любая строка, в которой есть хотя бы один символ (даже пробел), считается истинной, и только пустая строка `bool("")` дает `False`.

### Защита от «русской запятой» при вводе дробей
В школе мы пишем $3{,}14$ через запятую, но Python требует точку `3.14`. Чтобы программа не падала из-за привычки пользователя, заменяем запятую на точку прямо на лету:

```python
weight = float(input("Введите вес модели: ").replace(",", "."))
```

## 2. Арифметические операторы: три вида деления

Помимо сложения `+`, вычитания `-` и умножения `*`, в Python есть четыре важнейших оператора для инженерных расчетов:

| Оператор | Название | Пример | Результат | Особенность |
| :---: | :--- | :---: | :---: | :--- |
| `/` | Истинное деление (true division) | `17 / 5` | `3.4` | **Всегда** возвращает `float` (даже `10 / 2` даст `5.0`). |
| `//` | Целочисленное деление (floor division) | `17 // 5` | `3` | Сколько **целых** раз делитель помещается в числе. |
| `%` | Остаток от деления (modulo) | `17 % 5` | `2` | Остаток после деления нацело (незаменим для часов и циклов). |
| `**` | Возведение в степень (exponentiation) | `2 ** 10` | `1024` | Считает степени ($2^{10} = 1024$ байт в килобайте). |

Для любого целого числа $A$ и натурального делителя $B$ всегда выполняется фундаментальное тождество деления с остатком:

$$A = (A \text{ // } B) \times B + (A \bmod B)$$

## 3. Форматированные строки (f-strings) и парадокс $0.1 + 0.2$

Чтобы не склеивать строки и числа плюсами, перед открывающей кавычкой ставят букву `f`, а переменные и формулы пишут прямо внутри фигурных скобок `{}`:

```python
accuracy = 94.5678
minutes = 5
seconds = 7

# Модификатор :.2f округляет дробь при выводе до 2 знаков после точки
# Модификатор :02d дописывает ведущий ноль, чтобы цифра занимала ровно 2 позиции
print(f"Точность: {accuracy:.2f}% | Время: {minutes:02d}:{seconds:02d}")
# Выведет: Точность: 94.57% | Время: 05:07
```

### Почему `0.1 + 0.2` равно `0.30000000000000004`?
Процессор (CPU) хранит числа типа `float` в двоичной системе счисления (стандарт IEEE 754). Как в десятичной системе дробь $\frac{1}{3} = 0.3333\dots$ бесконечна, так в двоичной системе число $0.1$ превращается в бесконечную периодическую дробь! Из-за обрезания хвоста на границе $64$ бит накапливается микроскопическая погрешность округления (floating-point inaccuracy).

А встроенная функция `round(x)` в Python использует **банковское округление (banker's rounding)** — округление половинок `.5` к ближайшему **четному** целому числу: `round(2.5)` даст `2`, а `round(3.5)` даст `4`!

## 📚 Словарь разработчика

* **Приведение типов (type casting)** — явное преобразование значения из одного типа данных в другой (например, из `str` в `int`).
* **Конкатенация (concatenation)** — операция склеивания двух или более строк в одну с помощью оператора `+`.
* **Усечение (truncation)** — отбрасывание дробной части числа без математического округления при вызове `int()`.
* **Банковское округление (banker's rounding)** — правило округления чисел, оканчивающихся на $.5$, к ближайшему четному целому для снижения статистической ошибки.
