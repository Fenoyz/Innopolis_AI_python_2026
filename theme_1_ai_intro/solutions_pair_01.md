## 1. Подводные камни, крайние случаи (edge cases) и железо

* **Риск зависания при блокирующем вводе (blocking I/O):** На Уроке 2 ребята впервые запускают `input()`. Если ученик запустит скрипт в IDE, не кликнет мышкой внутрь консоли перед вводом текста или нажмет кнопку запуска повторно, в оперативной памяти (RAM) повиснет старый процесс Python. Сразу покажи правило: сначала останавливаем старый запуск кнопкой Stop (или `Ctrl + C`), кликаем в терминал и только потом печатаем.
* **Крайний случай (edge case) деления на ноль в задаче «Босса»:** Если пользователь просто ударит по клавише `Enter` за долю миллисекунды или системный таймер Windows 10 вернет разницу `0.0`, расчет скорости $v = L / \Delta t$ упадет с ошибкой `ZeroDivisionError`. Обязательно страхуем знаменатель через `max(0.001, elapsed_time)`.
* **Оптимизация под учебный ПК (Xeon E5-2620 v3, $16\text{ ГБ}$ RAM):** Для старта используем чистый стандартный интерпретатор Python без тяжелых окружений — скрипты запускаются мгновенно.

## 2. Поминутный план и схемы для доски (Урок 1 — Теория, $40$ мин)

### Схема №1 на доске ($0\text{–}15$ мин): Классика против Машинного обучения

```text
КЛАССИЧЕСКИЙ КОД (Экспертная система):
[ Правила (пишет человек) ] + [ Данные ] ===> [ Ответ ]

МАШИННОЕ ОБУЧЕНИЕ (Machine Learning):
[ Данные ] + [ Правильные ответы ] ===> [ Обученная модель (Правила) ]
```

* **Как объяснять:** Попроси ребят придумать правило на `if/else`, как отличить кота от собаки по пикселям фотографии. Через минуту они поймут, что уши могут быть закрыты, свет разный, ракурс сбоку — вручную правила не написать! Здесь и вступает в игру машинное обучение (machine learning).

### Схема №2 на доске ($15\text{–}30$ мин): Вероятности токенов в LLM
Запиши фразу и распределение вероятностей следующего слова:

$$\text{«На улице идет сильный...»} \longrightarrow \begin{cases} \text{дождь } (0.70) \\ \text{снег } (0.25) \\ \text{пельмень } (0.0001) \end{cases}$$

* **Как объяснять:** Языковая модель (LLM) не «понимает» физику дождя — она вычисляет наиболее вероятное продолжение текста. Поэтому при нехватке точных данных она уверенно склеивает правдоподобные слова, порождая галлюцинацию (hallucination).

### Разбор истории и цепочки рассуждений ($30\text{–}40$ мин)
* Фиксируем на доске причины «зим ИИ» (AI winters): слабые процессоры (CPU) $+$ отсутствие больших данных (Big Data). Показываем прием цепочки рассуждений (Chain-of-Thought) перед стартом практики.

### Эталонное решение Задания 3 — Уровень «Босс» (`token_simulator.py`)

```python
# Решение уровня «Босс» (Пара 1): token_simulator.py
import random
import time


def generate_next_token(prompt: str, temperature: float = 0.0) -> str:
    """Выбирает следующий токен по таблице весов с учетом температуры генерации."""
    probabilities = {
        "поможет автоматизировать рутину": 0.55,
        "изменит разработку видеоигр": 0.30,
        "потребует апгрейда оперативной памяти": 0.10,
        "научится шутить лучше стендаперов": 0.05,
    }

    tokens = list(probabilities.keys())
    weights = list(probabilities.values())

    if temperature <= 0.0:
        # Жадный поиск (greedy decoding): берем ключ с максимальным весом
        best = max(probabilities, key=probabilities.get)
        return f"{prompt} {best} [Greedy: P={probabilities[best]}]"

    # Пересчитываем веса с учетом температуры T > 0
    scaled_weights = [w ** (1.0 / temperature) for w in weights]
    picked = random.choices(tokens, weights=scaled_weights, k=1)[0]
    return f"{prompt} {picked} [Sampling: T={temperature}]"


def check_human_typing() -> None:
    """Измеряет скорость ввода ответа для защиты теста Тьюринга от ботов."""
    print("\n=== ТАЙМИНГ-ДЕТЕКТОР ТЕСТА ТЬЮРИНГА ===")
    start_ts = time.time()
    reply = input("Судья: Опиши одним предложением погоду за окном -> ")
    # Защита от деления на ноль через нижний порог 0.001 сек
    elapsed = max(0.001, time.time() - start_ts)

    clean_len = len(reply.strip())
    speed = clean_len / elapsed

    print(f"Длина: {clean_len} симв. | Время: {elapsed:.2f} сек. | Скорость: {speed:.2f} симв./сек.")

    if clean_len < 3:
        print("ВЕРДИКТ: [ПОДОЗРЕНИЕ НА БОТА] Слишком короткий ответ!")
    elif speed > 15.0:
        print("ВЕРДИКТ: [ПОДОЗРЕНИЕ НА БОТА] Мгновенная вставка из буфера или автоскрипт!")
    else:
        print("ВЕРДИКТ: [ПОДТВЕРЖДЕН ЧЕЛОВЕК] Естественный темп печати.")


if __name__ == "__main__":
    phrase = "Искусственный интеллект скоро"
    print("Режим T = 0.0:", generate_next_token(phrase, temperature=0.0))
    for attempt in range(1, 4):
        print(f"Режим T = 1.4 (попытка {attempt}):", generate_next_token(phrase, temperature=1.4))

    check_human_typing()
```
