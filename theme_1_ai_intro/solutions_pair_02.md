## 1. Подводные камни, крайние случаи (edge cases) и железо

* **Методический риск потери динамики:** По учебному плану программирование формально стартует в Теме 2, но вторая пара подряд из одних разговоров снизит вовлеченность подростков. Задания `vision_matrix.py` и `recommender_engine.py` закрывают обе цели: мы предметно изучаем сферы применения ИИ (Computer Vision и Recommender Systems) и одновременно набиваем руку в Python!
* **Крайний случай (edge case) в задаче «Босса»:** Если считать косинусное сходство (cosine similarity) и пользователь введет все нули `(0, 0, 0)`, длина вектора станет равна $0$, что вызовет ошибку `ZeroDivisionError`. Евклидово расстояние $d(U, G)$ этого недостатка лишено и работает стабильно при любых нулевых векторах! Максимальное расстояние между противоположными углами куба $[0, 10]^3$ равно:
  $$d_{\max} = \sqrt{10^2 + 10^2 + 10^2} = \sqrt{300} \approx 17.32$$
* **Кодировка символов псевдографики в Windows 10:** Символы `█` и `░` отлично отображаются в современных шрифтах VS Code и терминале PowerShell, но при сохранении файла убедись, что в редакторе стоит кодировка `UTF-8`.

## 2. Поминутный план и схемы для доски (Урок 3 — Теория, $40$ мин)

### Схема №1 на доске ($0\text{–}20$ мин): Четыре индустрии и перевод в числа
Раздели доску на $4$ квадранта и покажи, во что превращаются данные внутри оперативной памяти (RAM):

* **CV (Зрение):** Фотография $\longrightarrow$ таблица чисел яркости пикселей от $0$ до $255$.
* **NLP (Язык):** Сообщение в чате $\longrightarrow$ список номеров токенов `[1542, 89, 412]`.
* **RecSys (Рекомендации):** Поведение игрока $\longrightarrow$ вектор оценок `(9, 2, 10)`.
* **GenAI (Генерация):** Случайный шум $+$ текстовый запрос $\longrightarrow$ новая картинка или звук.

### Схема №2 на доске ($20\text{–}40$ мин): Геометрия рекомендаций
Нарисуй систему координат с осями $X$ («Экшен») и $Y$ («Сюжет») от $0$ до $10$:
* Поставь точку **Игрок $(8; 2)$**, рядом точку **Шутер $(9; 1)$**, а далеко вверху — **Квест $(1; 9)$**.
* **Объяснение математика:** Рекомендательный ИИ просто ищет ближайшие точки на графике по теореме Пифагора!

### Эталонное решение Задания 3 — Уровень «Босс» (`recommender_engine.py`)

```python
# Решение уровня «Босс» (Пара 2, Задание 3): recommender_engine.py
import math


def euclidean_distance(vec_a: tuple, vec_b: tuple) -> float:
    """Считает евклидово расстояние между двумя 3D-векторами признаков."""
    return math.sqrt(
        (vec_a[0] - vec_b[0]) ** 2
        + (vec_a[1] - vec_b[1]) ** 2
        + (vec_a[2] - vec_b[2]) ** 2
    )


def main() -> None:
    # База игр: название -> (Экшен, Тактика, Командность) по шкале 0..10
    games_db = {
        "Valorant": (9, 8, 10),
        "League of Legends": (8, 9, 10),
        "Portal 2": (3, 10, 5),
        "Don't Starve Together": (5, 7, 9),
        "DOOM Eternal": (10, 4, 0),
    }

    print("=== ПРОТОТИП РЕКОМЕНДАТЕЛЬНОГО ДВИЖКА ИГР ===")
    u_act = float(input("Ваша тяга к динамике и экшену (0-10): "))
    u_tac = float(input("Ваша любовь к тактике и головоломкам (0-10): "))
    u_team = float(input("Ваше желание играть в команде (0-10): "))
    user_vec = (u_act, u_tac, u_team)

    # Максимально возможное расстояние в кубе [0..10]^3 равно sqrt(300)
    max_dist = math.sqrt(300.0)
    results = []

    for title, game_vec in games_db.items():
        dist = euclidean_distance(user_vec, game_vec)
        # Переводим расстояние в процент сходства от 0% до 100%
        match_pct = max(0.0, (1.0 - dist / max_dist) * 100.0)
        results.append((match_pct, dist, title))

    # Сортируем по убыванию процента совпадения
    results.sort(reverse=True)

    print("\n--- ПЕРСОНАЛЬНЫЙ ТОП РЕКОМЕНДАЦИЙ ---")
    for pct, dist, title in results:
        blocks = round(pct / 10)
        bar = "█" * blocks + "░" * (10 - blocks)
        print(f"[{bar}] {pct:5.1f}% (d={dist:.2f}) -> {title}")


if __name__ == "__main__":
    main()
```
