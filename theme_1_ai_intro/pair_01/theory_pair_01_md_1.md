## 1. Иерархия технологий: $\text{AI} \supset \text{ML} \supset \text{DL}$

В новостях термины «искусственный интеллект», «машинное обучение» и «нейросети» часто используют как синонимы, но для разработчика это матрешка из трех уровней вложенности:

$$\text{AI} \supset \text{ML} \supset \text{DL}$$

```text
+-------------------------------------------------------------------+
| Искусственный интеллект (AI - Artificial Intelligence)            |
| Любая программа, имитирующая разумные решения (даже на правилах)  |
|                                                                   |
|   +-----------------------------------------------------------+   |
|   | Машинное обучение (ML - Machine Learning)                 |   |
|   | Алгоритмы, находящие закономерности в таблицах и данных   |   |
|   |                                                           |   |
|   |   +---------------------------------------------------+   |   |
|   |   | Глубокое обучение (DL - Deep Learning)            |   |   |
|   |   | Многослойные нейронные сети (текст, звук, видео)  |   |   |
|   |   +---------------------------------------------------+   |   |
|   +-----------------------------------------------------------+   |
+-------------------------------------------------------------------+
```

* **Искусственный интеллект (Artificial Intelligence — AI):** самая широкая область информатики. Даже простой бот (NPC) в ретро-игре, бегущий по жестко заданному маршруту, формально относится к примитивному ИИ.
* **Машинное обучение (Machine Learning — ML):** раздел ИИ, где программист **не пишет правила вручную**, а передает алгоритму набор данных (dataset), чтобы компьютер сам вывел математическую закономерность.
* **Глубокое обучение (Deep Learning — DL):** подраздел машинного обучения на базе многослойных искусственных нейронных сетей (artificial neural networks), способных генерировать код, изображения и вести осмысленный диалог.

## 2. Смена парадигмы: Классический код против ML

Представь задачу: нужно автоматически отделять спам-сообщения от обычных писем.

* **Классическое программирование (экспертная система / expert system):** человек сам формулирует жесткие условия (*«если в письме есть слово "выигрыш" — отправить в спам»*).

$$\text{Правила (Код)} + \text{Входные данные} \longrightarrow \text{Ответ}$$

* **Машинное обучение (Machine Learning):** мы загружаем в алгоритм $10\,000$ размеченных писем, и программа сама вычисляет веса слов и скрытые признаки спама.

$$\text{Входные данные} + \text{Правильные ответы} \longrightarrow \text{Обученная модель (Правила)}$$

> [!IMPORTANT]
> **Визуальная аналогия:** Классический код — это строгий кулинарный рецепт пельменей в граммах. Машинное обучение — это когда ты показал другу $1000$ готовых пельменей, и он сам понял принцип лепки.

## 3. Узкий ИИ против Общего ИИ

* **Узкий искусственный интеллект (Artificial Narrow Intelligence — ANI):** решает конкретный класс задач (играет в шахматы, распознает лица, предсказывает текст) быстрее человека, но не обладает сознанием и жизненным опытом. **Все существующие сегодня модели относятся к узкому ИИ.**
* **Общий искусственный интеллект (Artificial General Intelligence — AGI):** гипотетическая система будущего, способная самостоятельно обучаться любой интеллектуальной задаче в реальном мире наравне с человеком.

## 4. Ключевые вехи истории и «Зимы ИИ»

История ИИ развивалась волнами: за громкими открытиями следовали **«зимы ИИ» (AI winters)** — периоды резкого сокращения финансирования из-за завышенных ожиданий и нехватки мощности компьютеров.

* **$1950$ год — Тест Тьюринга (Turing test):** Алан Тьюринг предложил критерий оценки разума машины через текстовую переписку с судьей вслепую.
* **$1956$ год — Дартмутский семинар:** официальное рождение термина *Artificial Intelligence*.
* **$1970$-е и конец $1980$-х — Первая и Вторая «зимы ИИ»:** процессоры (CPU) не справлялись со сложными расчетами, а цифровых больших данных (Big Data) еще не существовало.
* **$1997$ год — Победа над чемпионом мира:** шахматный суперкомпьютер IBM Deep Blue обыграл Гарри Каспарова.
* **$2012$ год — Революция глубокого обучения:** нейросеть AlexNet доказала эффективность обучения на графических процессорах (GPU) в конкурсе распознавания изображений ImageNet.
* **$2017$ год — Архитектура трансформеров (Transformers):** появление механизма внимания (attention mechanism), ставшего фундаментом всех современных больших языковых моделей (Large Language Models — LLM).

---

## 5. Как думает языковая модель и откуда берутся галлюцинации

Большая языковая модель (LLM) разбивает текст на фрагменты — **токены (tokens)** — и на каждом шаге вычисляет условную вероятность следующего токена $w_t$:

$$P(w_t \mid w_1, w_2, \dots, w_{t-1})$$

* **Галлюцинация (hallucination):** ситуация, когда модель генерирует правдоподобный по форме, но фактически ложный ответ (вымышленную дату, несуществующую команду Python), так как опирается на статистику слов, а не на базу проверенных фактов.
* **Цепочка рассуждений (Chain-of-Thought — CoT):** прием инженерии запросов (prompt engineering), при котором мы просим модель сначала выписать пошаговую логику решения и только в конце дать ответ. Это резко снижает риск ошибки!

## 📚 Словарь разработчика

* **Набор данных (dataset)** — структурированная коллекция примеров (таблица, тексты, снимки) для обучения алгоритма.
* **Токен (token)** — минимальная единица текста для языковой модели (слово, слог или знак препинания).
* **Галлюцинация (hallucination)** — уверенная выдумка нейросети, возникающая из-за вероятностной природы генерации текста.
* **Цепочка рассуждений (Chain-of-Thought)** — метод построения запроса с обязательным выводом промежуточных логических шагов.
