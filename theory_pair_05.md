## 1. Матрешка технологий: AI $\supset$ ML $\supset$ DL

Часто слова «искусственный интеллект», «машинное обучение» и «нейросети» используют как синонимы, но для разработчика это три разных уровня вложенности:

$$\text{AI (Искусственный интеллект)} \supset \text{ML (Машинное обучение)} \supset \text{DL (Глубокое обучение)}$$

```text
+-------------------------------------------------------------------+
| Искусственный интеллект (AI — Artificial Intelligence)            |
| Любая система, имитирующая разумное поведение (даже на if/else)   |
|                                                                   |
|   +-----------------------------------------------------------+   |
|   | Машинное обучение (ML — Machine Learning)                 |   |
|   | Алгоритмы, которые сами находят закономерности в данных   |   |
|   |                                                           |   |
|   |   +---------------------------------------------------+   |   |
|   |   | Глубокое обучение (DL — Deep Learning)            |   |   |
|   |   | Многослойные нейронные сети (LLM, генерация фото) |   |   |
|   |   +---------------------------------------------------+   |   |
|   +-----------------------------------------------------------+   |
+-------------------------------------------------------------------+
```

* **AI (Artificial Intelligence / Искусственный интеллект):** широкая область компьютерных наук. Даже простой бот в старой видеоигре, который идет на игрока по жестко заданным координатам, формально считается примитивным ИИ.
* **ML (Machine Learning / Машинное обучение):** подраздел ИИ, где мы **не пишем правила вручную**, а скармливаем алгоритму таблицу с данными (датасет), чтобы он сам вывел математическую формулу. Именно этим мы будем плотно заниматься в **Модулях 2 и 3**.
* **DL (Deep Learning / Глубокое обучение):** сложные многослойные нейросети, способные распознавать лица на видео, генерировать музыку и вести диалог на естественном языке.

## 2. Смена парадигмы: Классический код против ML

Представь, что тебе нужно написать программу, которая отличает спам-сообщение от важного письма.

### Как работает классическое программирование (Экспертная система)
Программист сам придумывает правила (например: *«Если в тексте есть слово "Купи" — это спам»*).

$$\text{Правила (Код)} + \text{Данные} \longrightarrow \text{Ответы}$$

### Как работает Машинное обучение (Machine Learning)
Мы берем $10\,000$ писем, где человек уже проставил метки «Спам» или «Не спам», и запускаем алгоритм обучения. Модель сама находит скрытые зависимости!

$$\text{Данные} + \text{Правильные ответы} \longrightarrow \text{Правила (Обученная модель)}$$

> [!IMPORTANT]
> **Метафора разработчика:** Классический код — это когда ты дал другу строгий пошаговый рецепт пельменей в граммах. Машинное обучение — это когда ты показал другу $1000$ готовых пельменей, и он сам понял принцип лепки.

## 3. Слабый ИИ (Narrow AI) vs Сильный ИИ (AGI)

Все существующие сегодня нейросети относятся к первой категории:

| Характеристика | Узкий / Слабый ИИ (ANI — Artificial Narrow Intelligence) | Общий / Сильный ИИ (AGI — Artificial General Intelligence) |
| :--- | :--- | :--- |
| **Что умеет** | Решает одну конкретную задачу (играет в шахматы, пишет код, рисует арты) лучше большинства людей. | Способен самостоятельно учиться чему угодно в реальном мире наравне с человеком. |
| **Понимание мира** | Нет сознания и жизненного опыта; оперирует только математической статистикой. | Обладает самосознанием, здравым смыслом и переносом опыта из одной сферы в другую. |
| **Статус сегодня** | **Реальность** (ChatGPT, Gemini, Midjourney, автопилоты). | **Гипотеза / Будущее** (пока существует только в научной фантастике). |

## 4. Хронология: Повороты истории и «Зимы ИИ»

История ИИ — это череда громких прорывов и периодов разочарования, которые ученые называют **«Зимами ИИ» (AI Winters)**, когда финансирование лабораторий сокращалось почти до нуля.

1. **$1950$ год — Тест Тьюринга (Turing Test):** Британский математик Алан Тьюринг публикует статью *«Вычислительные машины и разум»*. Он предлагает «игру в имитацию»: если судья переписывается в чате с человеком и машиной и за $5$ минут не может точно определить, кто есть кто, машина считается «мыслящей».
2. **$1956$ год — Дартмутский семинар:** Джон Маккарти официально вводит термин *Artificial Intelligence*. Ученые уверены, что создадут полноценный искусственный разум за одно лето.
3. **$1970\text{-е}$ и конец $1980\text{-х}$ — Первая и Вторая «Зимы ИИ»:** Почему проекты замораживали?
   * **Нехватка вычислительной мощности (Compute):** Процессоры того времени были в миллионы раз слабее современного смартфона.
   * **Отсутствие больших данных (Big Data):** Не было интернета, цифровых архивов текста и фотографий для обучения.
   * **Завышенные ожидания (Hype):** Первые алгоритмы пасовали перед задачами реального мира.
4. **$1997$ год — Триумф в шахматах:** Суперкомпьютер IBM Deep Blue побеждает чемпиона мира Гарри Каспарова за счет перебора $200\text{ млн}$ позиций в секунду.
5. **$2012$ год — Революция на видеокартах (GPU):** Нейросеть AlexNet с огромным отрывом побеждает в конкурсе распознавания картинок ImageNet. Оказалось, что видеокарты идеально подходят для обучения нейросетей!
6. **$2017\text{ год — настоящее время}$ — Эра Трансформеров (Transformers):** Инженеры придумывают архитектуру *Transformer* с механизмом внимания (*Attention*), которая породила современные большие языковые модели (LLM).

## 5. Почему нейросети «галлюцинируют» и как этим управлять?

Когда ты задаешь вопрос большой языковой модели (LLM), она не ищет ответ в энциклопедии. Она разбивает твой текст на кусочки — **токены (tokens)** — и вычисляет вероятность каждого следующего слова:

$$P(w_t \mid w_1, w_2, \dots, w_{t-1})$$

* **Галлюцинация (Hallucination):** Ситуация, когда нейросеть уверенно выдумывает несуществующий факт, ложную дату или фальшивую функцию в Python, потому что эти слова статистически красиво складываются в предложение.
* **Промпт-инжиниринг (Prompt Engineering):** Искусство формулировать входной запрос так, чтобы направить вероятности модели в нужное русло.
* **Цепочка рассуждений (Chain-of-Thought / CoT):** Если заставить модель не выдавать ответ сразу, а **рассуждать по шагам** (написав: *«Решай задачу последовательно шаг за шагом, проверяя каждое действие»*), количество логических ошибок падает в несколько раз!

## 🔍 Словарь разработчика на Пару 1

* **Dataset (Датасет)** — структурированный набор данных (таблица, папка с фото или текстами) для обучения модели.
* **Token (Токен)** — базовая единица текста для нейросети (слово, часть слова или символ).
* **Hallucination (Галлюцинация)** — правдоподобная, но фактически неверная информация, сгенерированная ИИ.
* **Chain-of-Thought (Цепочка рассуждений)** — техника промптинга, заставляющая ИИ выводить промежуточные шаги логики перед финальным ответом.
