## 1. Программирование без ветвлений (Branchless Programming)

Операторы сравнения проверяют соотношение двух значений и всегда возвращают логический тип `bool` (`True` или `False`):
* `>` (больше), `<` (меньше), `>=` ($\ge$ больше или равно), `<=` ($\le$ меньше или равно).
* `==` (проверка равенства — **два** знака равно!), `!=` ($\ne$ не равно).

В архитектуре языка Python тип `bool` является прямым наследником целого числа `int`: в любых арифметических формулах **`True` ведет себя как $1$, а `False` — как $0$**!

```python
print(True + True)    # Выведет: 2
print(True * 500)     # Выведет: 500
print(False * 500)    # Выведет: 0
```

Это позволяет управлять расчетами как электрическим тумблером без использования `if`:

$$\text{Итог} = \text{База} + (\text{Условие}) \times \text{Бонус}$$

### Математический щит от деления на ноль (`ZeroDivisionError`)
Если пользователь введет скорость `0`, обычное деление `1000 // speed` уронит программу. Защитим знаменатель булевым тумблером:

$$x_{\text{safe}} = x + (x == 0) \times 1$$

* Если $x = 25$, условие $(25 == 0)$ ложно ($0$), и знаменатель остается $25 + 0 = 25$.
* Если $x = 0$, условие $(0 == 0)$ истинно ($1$), и знаменатель превращается в $0 + 1 = 1$, спасая скрипт от аварии!

## 2. Консольная графика и ограничение диапазона (Clamping)

В Python строку можно умножить на целое число, чтобы мгновенно повторить символ нужное число раз:

```python
bar = "█" * 8 + "░" * 2
print(f"Прогресс: [{bar}] 80%")  # Выведет: Прогресс: [████████░░] 80%
```

> [!WARNING]
> **Скрытый баг крайнего случая (edge case):** Если пользователь введет занятую память $25\text{ ГБ}$ из $16\text{ ГБ}$, число пустых клеток станет отрицательным ($-11$). В Python умножение строки на отрицательное число (`"░" * -11`) молча возвращает пустую строку `""`, и шкала расползается на весь экран!

### Формула «бортиков» — Ограничение диапазона (Clamping)
Чтобы жестко зажать любое число $x$ в безопасный коридор от $0$ до $20$, используют связку встроенных функций минимума `min()` и максимума `max()`:

$$x_{\text{safe}} = \max(0, \min(20, x))$$

```text
           Левый бортик max(0, ...)          Правый бортик min(20, ...)
                     |                                   |
  -5 (отсечется в 0) |======== Безопасная зона [0..20] ==| 99 (отсечется в 20)
```

А чтобы найти разницу между двумя числами без знака «минус», применяется встроенная функция модуля числа `abs(a - b)` ($|a - b|$).

## 📚 Словарь разработчика

* **Программирование без ветвлений (branchless programming)** — техника замены условных переходов математическими и логическими операциями для ускорения кода.
* **Ограничение диапазона (clamping)** — принудительное удержание переменной в заданных границах $[a, b]$ с помощью `min()` и `max()`.
* **Индикатор выполнения (progress bar)** — графическая или текстовая шкала, наглядно отображающая долю завершенной работы или занятого ресурса.
