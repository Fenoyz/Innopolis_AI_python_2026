## 1. Переменные в Python — это стикеры, а не коробки!

Новичкам часто говорят, что **переменная (variable)** — это ящик, куда кладут число. В языке Python всё устроено гораздо интереснее: объект создается в **оперативной памяти (Random Access Memory — RAM)**, а переменная работает как **стикер-ссылка (object reference)**, наклеенный на этот объект!

```text
Имена (Стикеры)              Оперативная память ПК (RAM - 16 GB)
+-------------+             +-------------------------------------+
| score       | ----------> | Объект int: 100  (id: 14071258...)  |
+-------------+             +-------------------------------------+
| bot_name    | ----------> | Объект str: "AI" (id: 21984410...)  |
+-------------+             +-------------------------------------+
```

* Знак `=` — это **оператор присваивания (assignment operator)**, а не математическое равенство. Команда `score = 200` создает в памяти новый объект `200` и переклеивает на него стикер `score`.
* А что происходит со старым объектом `100`, на который больше не указывает ни один стикер? Его автоматически находит и удаляет из памяти **сборщик мусора (garbage collector)**!

### Правила именования переменных (стандарт PEP 8)
* Используем **змеиный регистр (snake_case)**: маленькие латинские буквы, а слова разделяем нижним подчеркиванием (`user_age`, `max_tokens`, `gpu_temp`).
* Имя **не может** начинаться с цифры (`1player` вызовет синтаксическую ошибку `SyntaxError`) и содержать пробелы или дефисы.

## 2. Четыре базовых типа данных (Data Types)

В Python действует **динамическая типизация (dynamic typing)** — интерпретатор сам определяет тип объекта в момент присваивания:

| Тип в Python | Полное название | Примеры значений | Для чего нужен в ИИ-проектах |
| :--- | :--- | :--- | :--- |
| `int` | Целое число (integer) | `42`, `-15`, `0`, `1_000_000` | Количество эпох обучения, число ядер CPU, индекс элемента. |
| `float` | Число с плавающей точкой (floating-point) | `3.14`, `-0.01`, `2.0` | Веса нейросети, температура генерации, процент точности. |
| `str` | Строка (string) | `"Привет"`, `'GPT'`, `"500"` | Текст запроса (промпта), имя файла, сообщения в чате. |
| `bool` | Логический тип (boolean) | `True`, `False` | Флаги состояния (включен ли сервер, пройден ли порог). |

> [!WARNING]
> Обрати внимание: `500` — это число (`int`), его можно делить и возводить в степень. А `"500"` в кавычках — это строка текста (`str`), как номер маршрутки! Узнать тип любого объекта позволяет функция `type(x)`, а его точный адрес в памяти — функция `id(x)`.

## 3. Потоки ввода и вывода: `print()` и `input()`

### Вывод данных на экран — `print()`
Функция `print()` принимает любое количество аргументов через запятую и имеет два секретных управляющих параметра:
* `sep` (separator — разделитель): что ставить **между** значениями (по умолчанию пробел `" "`).
* `end` (окончание): что ставить **в самом конце** вывода (по умолчанию перенос на новую строку `"\n"`).
* Полезные управляющие последовательности (escape sequences): `\n` — новая строка, `\t` — ровный отступ табуляции.

```python
print("Модуль", "ИИ", "активен", sep=" :: ", end=" --> ")
print("Готов к работе!")
# Выведет в одну строку: Модуль :: ИИ :: активен --> Готов к работе!
```

### Чтение данных с клавиатуры — `input()`
Функция `input("Подсказка: ")` ставит выполнение скрипта на паузу (**блокирующий ввод / blocking I/O**), ждет ввода текста с клавиатуры до нажатия клавиши `Enter` и возвращает результат в переменную.

> [!IMPORTANT]
> **Главный закон `input()`:** Что бы ни напечатал пользователь с клавиатуры (даже цифры `42` или слово `True`), функция `input()` **ВСЕГДА возвращает строку (`str`)**!

## 📚 Словарь разработчика

* **Переменная (variable)** — именованная ссылка в коде, указывающая на объект в оперативной памяти компьютера.
* **Сборщик мусора (garbage collector)** — встроенный механизм Python, автоматически освобождающий память от неиспользуемых объектов.
* **Динамическая типизация (dynamic typing)** — свойство языка, при котором тип данных привязан к самому объекту, а не жестко закреплен за именем переменной.
* **Блокирующий ввод (blocking I/O)** — режим ожидания, в котором программа полностью останавливается, пока пользователь не отправит данные в консоль.
