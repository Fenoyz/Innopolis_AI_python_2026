## Разминка с преподавателем ($10$ минут). «Ловушки дробей и защита от запятой»

Создай в папке `AI_Course` файл `float_trap.py`, запусти его и проверь с вводом через точку и через запятую:

```python
raw_text = input("Введите вес модели в ГБ (можно через точку или запятую): ")
weight_gb = float(raw_text.replace(",", "."))

print("Парадокс двоичной памяти (0.1 + 0.2):", 0.1 + 0.2)
print(f"Чистый вывод веса в МБ: {weight_gb * 1024:.2f} МБ")
print("Банковское округление Python -> round(2.5):", round(2.5), "| round(3.5):", round(3.5))
```

## 🛡 Задание 1 (Уровень «База»). Планировщик видеопамяти RX 570 `vram_planner.py`

На нашем учебном компьютере установлена видеокарта объемом $8\text{ ГБ}$ ($8192\text{ МБ}$ видеопамяти VRAM). Создай скрипт `vram_planner.py`:
* Запроси у пользователя два значения:
  1. Сколько мегабайт занимает сама загруженная ИИ-модель (`int`).
  2. Сколько мегабайт весит одна картинка высокого разрешения для обработки (`float`, с защитой `.replace(",", ".")`).
* Вычисли:
  * Объем свободной видеопамяти, оставшейся после загрузки модели.
  * Сколько **целых** картинок поместится в свободную память одновременно за один проход (через `//`, приведя итог к `int`).
  * Сколько мегабайт видеопамяти при этом останется незанятыми (через `%`).
* Выведи аккуратный отчет через f-строки, округлив остаток памяти до одного знака после точки (`:.1f`).

## 🔥 Задание 3 (Уровень «Босс»). Честное математическое округление и бинарный анализатор `binary_dataset_boss.py`

Создай в папке `AI_Course` скрипт `binary_dataset_boss.py`, решающий две задачи без условных операторов `if`:

* **Часть А — Школьное арифметическое округление:**
  * Поскольку встроенный `round(2.5)` в Python дает `2`, выведи и реализуй математическую формулу честного арифметического округления любого неотрицательного числа $x \ge 0$ до ближайшего целого с помощью только `int()` и сдвига на $+0.5$:
    $$R(x) = \text{int}(x + 0.5)$$
  * Продемонстрируй в консоли сравнение `round(x)` и твоей формулы на числах $2.4$, $2.5$ и $3.5$.
* **Часть Б — Поразрядный калькулятор веса RGB-датасета:**
  * Пользователь вводит количество несжатых фотографий в датасете (`photos`), ширину кадра (`width`), высоту кадра (`height`) в пикселях и глубину цвета в битах на пиксель (`bits_per_pixel`, например $24$ бита для стандартного RGB).
  * Переведи общий объем датасета из битов в байты ($1\text{ байт} = 8\text{ бит}$), а затем разложи это гигантское число по ступеням степеней $1024 = 2^{10}$: **Гигабайты, Мегабайты, Килобайты и Байты**, используя цепочку `//` и `%`.
