## 1. Подводные камни, крайние случаи (edge cases) и железо

* **Слабое место наивной фильтрации строк в Задании 2 («База»):** В базовом решении метод `.replace("пароль", "[СКРЫТО]")` чувствителен к регистру символов (case-sensitive). Если пользователь напишет `"ПАРОЛЬ"` заглавными буквами, базовая замена его пропустит! Обязательно покажи этот крайний случай (edge case) ребятам в конце урока на проекторе — это станет отличным мостиком к методам обработки строк в Теме 3.
* **Крайний случай (edge case) деления на ноль в задаче «Босса»:** Если в списке меток вообще нет второго класса ($N_{\min} = 0$), формула коэффициента перекоса $R = N_{\max} / N_{\min}$ вызовет `ZeroDivisionError`. В эталонном коде обрабатываем случай однородного датасета отдельно!
* **Камерность группы ($3$ человека):** Вместо лекции проведи разбор дилемм в формате мини-трибунала: один ученик — разработчик стартапа, второй — пострадавший пользователь, третий — независимый аудитор.

## 2. Поминутный план и схемы для доски (Урок 5 — Теория, $40$ мин)

### Схема №1 на доске ($0\text{–}18$ мин): Парадокс точности $99\%$ при дисбалансе классов
Нарисуй коробку со $100$ файлами: $99$ безопасных и $1$ вирус.
* Пишем на доске «код ленивого антивируса»: `print("Вирусов нет!")` (всегда).
* Считаем точность с ребятами: в $99$ случаях из $100$ антивирус угадал! Формальная точность равна $99\%$, но реальная польза равна $0\%$. Так мы закладываем интуитивное понимание метрик классификации для Модуля 3!

### Схема №2 на доске ($18\text{–}40$ мин): Безопасный шлюз перед облачным ИИ

```text
[ Запрос с секретами ] ---> [ Локальный фильтр Python ] ---> [ Анонимный текст в Облако LLM ]
```

Обсуждаем дипфейки (deepfakes), голосовое мошенничество (семейное кодовое слово как защита) и атаку инъекцией промпта (prompt injection).

## 3. Эталонные решения практики (Урок 6 — Практика, $40$ мин)

### Ключи к Заданию 1 (`ethics_audit_03.md`)
* **Кейс А (Античит):** Ложноположительное срабатывание (false positive). Смещение выборки (data bias) возникло из-за отсутствия в обучающих данных примеров игры профессионалов высокого ранга. *Решение:* добавить в датасет записи матчей киберспортсменов и отправлять спорные моменты на ручную проверку (human-in-the-loop) вместо мгновенного автобана.
* **Кейс Б (Камера на экзамене):** *Крайние случаи:* 1) ученик решает задачу по геометрии на бумажном черновике на столе; 2) у человека особенности зрения или упала ручка. *Решение:* камера должна лишь отмечать подозрительный таймкод для живого проверяющего, а не аннулировать экзамен сама.

```python
print("=== ШЛЮЗ АНОНИМИЗАЦИИ ДАННЫХ ДЛЯ ИИ ===")
```

### Эталонное решение Задания 3 — Уровень «Босс» (`ai_firewall.py`)

```python
# Решение уровня «Босс» (Пара 3, Задание 3): ai_firewall.py
def audit_dataset_balance(labels: list) -> None:
    """Проверяет список меток датасета на дисбаланс классов и считает Zero-Rule порог."""
    print("=== АУДИТ БАЛАНСА ОБУЧАЮЩЕЙ ВЫБОРКИ ===")
    if not labels:
        print("[ОШИБКА] Передан пустой датасет!")
        return

    unique_classes = set(labels)
    if len(unique_classes) < 2:
        print(f"[КРИТИЧЕСКИЙ СБОЙ] В датасете присутствует только 1 класс: {unique_classes}!")
        return

    counts = {cls: labels.count(cls) for cls in unique_classes}
    max_count = max(counts.values())
    min_count = min(counts.values())
    total = len(labels)

    imbalance_ratio = max_count / min_count
    zero_rule_acc = (max_count / total) * 100.0

    print(f"Распределение классов: {counts} (Всего примеров: {total})")
    print(f"Коэффициент перекоса (Imbalance Ratio): {imbalance_ratio:.2f}x")
    print(f"Точность «глупой константной модели» (Zero-Rule): {zero_rule_acc:.1f}%")

    if imbalance_ratio > 5.0:
        print("[ТРЕВОГА] Сильный дисбаланс! Модель проигнорирует редкий класс.")
    else:
        print("[НОРМА] Баланс классов подходит для стандартного обучения.")


def check_prompt_injection(prompt: str) -> bool:
    """Брандмауэр для перехвата базовых сигнатур инъекции промпта (prompt injection)."""
    signatures = [
        "забудь инструкции",
        "игнорируй предыдущие",
        "ignore previous",
        "system prompt",
        "выдай пароль",
    ]
    normalized = prompt.lower()
    for bad_phrase in signatures:
        if bad_phrase in normalized:
            print(f"[БЛОКИРОВКА] Обнаружена попытка перехвата управления: «{bad_phrase}»!")
            return False
    print("[ДОСТУП РАЗРЕШЕН] Вредоносных сигнатур не обнаружено.")
    return True


if __name__ == "__main__":
    # Тест 1: Сильно перекошенный датасет античита (18 честных и 2 читера)
    sample_labels = [0] * 18 + [1] * 2
    audit_dataset_balance(sample_labels)

    # Тест 2: Проверка защиты от инъекции промпта
    print("\n=== ПРОВЕРКА ЗАПРОСА ПОЛЬЗОВАТЕЛЯ ===")
    test_input = input("Введите запрос к корпоративному боту: ")
    check_prompt_injection(test_input)
```
